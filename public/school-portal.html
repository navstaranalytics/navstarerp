Bulk learner registration & enrolment

Download the official CSV template, fill one learner per row, then upload up to 5,000 learners in one CSV file (maximum 10 MB).

Download the school-generated template: it fills in your actual active classes and their linked streams. Keep the class and stream values paired as provided; do not type a stream belonging to another class. Required learner details: first_name, last_name, academic_year and class. Admission numbers are generated after validation; Assessment, UPI and NEMIS numbers are optional. For elective learning areas, enter the exact school-configured names separated by semicolons; compulsory areas are assigned automatically. Date of birth uses YYYY-MM-DD.

Bulk class enrolment · Existing learners

Use the same upload-and-correct workflow to enrol learners already registered in this school. Admission numbers are matched to existing learner records.

Download the template first, then fill one learner per row. Use the exact admission number, academic year, class and stream already in this school. The system checks that the learner exists, the class and stream match, and the learner is not already enrolled in that academic year before saving.

  1. Download the school-generated CSV template.
  2. Enter each learner admission number and the target academic year, class and stream.
  3. Do not change the column headings or invent class/stream names.
  4. Upload the CSV and read the validation summary. Correct every rejected row before retrying.
